The harness gates success on a fresh, visible, stable canvas and appropriate geometry/ink or an explicitly declared and independently white reference. It retains **all** confirmed bitmap-to-reference associations per trial, including through failed frames and reopen; failed observations never teach history. Exact replay against a different appearance fails without requiring an adjacent transition. True returns and byte-identical independent references at equal dimensions can reuse a bitmap. For measured performance pages, the relative RGB metric also compares each distinct aspect-compatible planned rival, even if no browser image for that rival has been confirmed. I separately tested all ordered rival pairs for the four performance inputs against the exact wrong reference and a one-channel, one-pixel digest perturbation, with empty histories. Coarse layout accepted all 48 wrong observations; the rival discriminator rejected all 48. Correct references passed. This is a bounded raster proxy: low-signal differences can remain ambiguous, resampling can conceal changes, unreferenced pages are not tested rivals, and identical sampled appearances do not establish PDF page-object identity. The viewport, stability wait and automation overhead also limit timing interpretation.
